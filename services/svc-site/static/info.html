平台接口索引

这个地址是给程序探测网关用的：程序直接请求返回一段 JSON，用浏览器打开看到的是本页说明。下面是网关对外的公共入口，网关地址是 https://apipay.sanrun.fun。

商户接入用到的入口

入口用途
POST /oauth/token用开放平台分配的 appKey / appSecret 换访问令牌，有效期 1 小时
/api/pay/v1/…商户支付开放 API：下单、查单、关单、退款、分账、提现、交易流水与按日账单汇总。字段与签名规则见 商户接入指南
GET /auth/.well-known/jwks.json平台签发令牌用的公钥（JWKS，RS256）
GET /docs浏览器打开是《商户支付开放 API 接入指南》；程序请求返回各服务 OpenAPI 文档索引（JSON）
GET /guide/isv《服务商入驻与运营指南》：服务商渠道参数、商户进件、通道配置、代理分润与对账说明
GET /platform/info本索引。程序请求返回 JSON，可用来探测网关是否在线

服务商与管理员控制台

地址谁用做什么
/api/pay/console/服务商 / 运营审核支付中心工作台：服务商、商户、应用·通道、进件审核、订单、分账、提现、代理分润、对账（详见 服务商入驻指南）
/api/openapi/console/管理员开放平台：为商户业务系统创建 appKey / appSecret、分配 pay.* 接口权限
/platform/console/管理员平台控制台：后台登录账号、服务状态

控制台都要先登录。在 首页 点「登录」，账号由平台管理员分配。
