我是商户 / 研发团队

开放 API 对接

适合已由服务商开好户的商家商城、小程序、门店收银、SaaS 或财务系统。

  • 获取凭据：向服务商领取开放平台 appKey / appSecret（换取 1 小时有效的 accessToken）以及应用的 App-Id / 签名密钥。
  • 下单与退款：请求 https://apipay.sanrun.fun/api/pay/v1/orders 统一下单（支持 WX_JSAPI、WX_NATIVE、ALI_QR 等），接收异步通知验签履约，支持全额或多次部分退款。
  • 查账与核账：通过 GET /api/pay/v1/bills/transactions 拉取支付与退款成功流水明细，通过 GET /api/pay/v1/bills/summary 获取北京时间按日汇总（含记账手续费、退款手续费冲回与入账净额）。
  • 沙箱联调：联调期可走 sandbox 通道不动真钱测通下单、回调、异常重试与查账，切正式通道无需改代码。

我是服务商 / 运营与审核人员

控制台操作

适合微信支付服务商、支付宝直付通 ISV、进件录单员、审核员与平台管理员。

  • 服务商证书配置：登记服务商档案，在「应用·通道」一次性配齐微信服务商商户号、APIv3 密钥、API 证书私钥与微信支付公钥（或支付宝直付通密钥），名下特约商户共用。
  • 商户进件与签约：上传营业执照、法人身份证、结算银行卡与门店场景照片，经提交人与审核员双人复核加密报送微信；签约完成后特约商户号自动写入商户渠道配置。
  • 应用通道与权限发放：为商户创建应用、按支付方式配置通道费率（随时可编辑或启停），配合开放平台签发 pay.order.*、pay.bill.query 等权限。
  • 代理分润与每日对账：支持最多 3 级代理商差额分润台账；一键开启每日自动下载微信/支付宝官方账单逐笔核对差异。

核心能力

特约商户进件

证件与银行卡号全程加密落库，支持双人复核、驳回免重填敏感号段、签约后子商户号自动回写。

聚合收款与退款

公众号、小程序、扫码、H5、网站、App 统一下单与部分退款，统一签名回调与后台自动补单。

商户查账与渠道对账

商户通过 API 实时拉取交易流水与按日汇总；服务商每日自动比对渠道官方账单排查长短款。

分账、提现与代理分润

支持订单分账、归集模式结算提现，以及最多 3 级代理商按成交与退款自动核算差额分润。
